## Run Locally

This is a static HTML portfolio and does not require a build tool or package installation.

1. Clone the repository:

   ```bash
   git clone https://github.com/bshni/portfolio.git
   cd portfolio
   ```

2. Open `index.html` in a browser.

For more reliable local link and asset handling, serve the repository with any static web server. For example:

```bash
npx serve .
```
