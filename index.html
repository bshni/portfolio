SQL Data Warehouse & Business Analytics

A retail data warehouse built from scratch in SQL Server on a Medallion Architecture (Bronze → Silver → Gold), modeled as a star schema, with analysis scripts and KPI report views on top. My first SQL project, built for DEPI Mini Project 2.

The challenge

Turn a single flat retail file (Central Superstore) into a proper analytical warehouse: a documented, repeatable load process and a model that business questions can be asked against.

What I built

  • Excel → CSV conversion script in Python, then BULK INSERT into a raw Bronze layer, with truncate-and-reload stored procedures for Bronze and Silver.
  • Gold layer as views: dim_customers, dim_products, dim_order_details and fact_sales, with surrogate keys and documented naming conventions.
  • Data quality checks for each layer, a gold-layer data catalog, and a star schema diagram.
  • Exploration and analysis scripts (change over time, cumulative, performance, part-to-whole) plus report_customers and report_products views covering recency, average order value, segmentation, and lifespan.

What I learned

The source data turned out to be already clean, so Silver stayed close to Bronze and only added a derived total_price column. Checking first and keeping each layer's job honest mattered more than adding transformations for show.

Superstore Retail Analytics

An end-to-end Python pipeline that turned 9,994 raw retail transactions into $284K in identified profit drivers and a pricing recommendation for three loss-making sub-categories.

The challenge

The Sample Superstore dataset arrived with missing values, duplicate rows, inconsistent formatting, and no engineered features — just raw transactions with no clear story yet.

What I built

A chainable OOP pipeline (SuperstoreCleaner, FeatureEngineer) with custom exception handling — cleaning, IQR outlier detection, memory optimization, and engineered fields like Profit Margin and Discount Bucket — followed by correlation and significance testing with scipy.stats.

The result

Discount and profit are significantly negatively correlated (r = -0.22); Tables, Bookcases, and Supplies account for most of the profit loss; West/Consumer is the strongest region-segment pair at $57K profit. Delivered as 11 visualizations, a dashboard, and an automated KPI report via a custom KPIReportGenerator class.
